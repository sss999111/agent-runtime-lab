## 一句话概述

从零实现通用任务型 Agent 运行时（纯 Python 标准库，不套框架），覆盖 ReAct 主循环、上下文压缩、三层记忆（向量检索）、并行调度、Skill 自进化、进度跟踪与断点续跑，用 19 个可自动判分的任务做消融实验，所有结论有真实运行数据支撑。

## 四段式亮点（直接放简历）

**1. 上下文组装与压缩 — 34% token 节省，零成功率损失**

- 实现四种上下文策略（full / window / state_card / summary），在长文本任务上做消融对比
- `state_card`（将早于窗口的步骤压成「工具名+参数+结果摘要」）相比全量减少 **34% 输入 token**，成功率 6/6 不变，耗时仅 +18%
- 发现 `window` 直接丢历史会逼模型重读文件（步数 5.7→6.5），`summary` 因额外模型调用导致耗时暴涨 14 倍，均为负收益

**2. 三层记忆与调度机制 — 不可完成任务变为 3 步完成**

- 设计 L1 工作记忆 / L2 情景轨迹 / L3 长期事实三层记忆，长期事实用**字符 n-gram + 余弦相似度**向量检索，优先返回与任务最相关的事实
- 对照实验：有长期记忆时任务 **4/4 通过（2.5 步）**，无记忆时 **0/2 跑满 8 步**（9488 tokens 浪费在试探）
- 实现调度器：`ThreadPoolExecutor` 并行工具调用 + `FailureBudget`（同签名连续失败 2 次强制换方法），避免空转

**3. Skill 体系与自进化 — 打法可沉淀、可热插拔、可自动淘汰**

- 设计 manifest 驱动的 Skill 机制：按触发词匹配任务，将 playbook 注入系统提示
- 实现 `learn_skill` 工具，Agent 可将成功经验自动沉淀为新 Skill 落盘，下次同类任务自动参照
- 实现 **Skill 健康度机制**：统计每个 Skill 的任务成功率，成功率 < 30% 且样本 ≥3 自动禁用（解决劣质 Skill 长期残留问题）

**4. 进度跟踪与断点续跑 — 对齐字节 Aime 论文思路**

- 参考字节 Aime 论文（arxiv 2507.11988）的 Progress Management，每步记录「已完成/下一步」并注入系统提示，让 Agent 拥有全局状态视图
- 实现 Checkpoint/Resume：每步保存执行状态，任务中断后用 `--resume` 从断点继续（1 步失败 → 续跑 3 步完成）
- 实现零额度 Mock 回归：预设脚本替代真实 LLM，**19 任务 × 4 策略全量回归 0 tokens、0.4 秒**，每次改动即可验证全链路
